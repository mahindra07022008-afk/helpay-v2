# Helpay 2.0

Helpay is a coupon and public-offer discovery web application in development.

**Status:** Development — not published. It uses Supabase for user accounts and moderated public offers. Real payments and coupon resale are not enabled.

## Source code

The complete source package should be imported into this repository before deployment. Do not upload secrets, service-role keys or database passwords.

## Planned deployment

GitHub → Cloudflare Pages; database and auth → Supabase. Publish only after authentication, database access policies and moderation are tested.
